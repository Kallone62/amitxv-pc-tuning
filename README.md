# my-pc-optimization

Personal, system-specific PC configuration and deployment repository.

This repository is built for **my own hardware and peripherals**, primarily around competitive CS2. It is **not a generic PC tuning guide**. Scripts, driver logic, game configuration, peripheral settings and BIOS notes should be interpreted against the exact system documented in `SYSTEM.md`.
